## Fonts, suite, and limits

Computed UI font was `"Source Sans Pro", sans-serif`; `document.fonts.status` was loaded in measured views. The request allowlist blocked all external requests, including remote fonts, so this is not a remote-font loading/sign-off test. Local fixture assets were allowed. No obvious manifest/rendering breakage was seen in initial fixture renders (`ginubh`, `z2jesw`).

Reviewed `verification/reset-consumption/reset.test.tsx`: it wraps the real route in React `StrictMode`, and its actual address helpers target `address-button-edit`, `input-address-1`, `address-button-save`, and `field-address-1` / `loan-subject-property:synthetic-a`, not borrower personal-address controls. The file contains 14 individual cases when parameterized cases are counted separately. Per requester, all 14 passed; this browser pass did not rerun the unit suite.
