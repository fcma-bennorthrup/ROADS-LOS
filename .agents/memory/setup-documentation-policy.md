name: Setup documentation policy
description: Owner-approved treatment of conflicting runtime configurations
---
Document both the local and Replit runtime configurations as observed, with compatibility explicitly unverified. Do not select one as authoritative or align runtime files as part of documentation corrections.

**Why:** The owner chose to describe both existing configurations rather than certify a supported runtime or authorize a toolchain change.

**How to apply:** Keep factual setup descriptions separate from support guarantees. Obtain separate authorization for runtime alignment, dependency-baseline acceptance, setup smoke testing or publication.
