description: User-approved repeated credit pull and borrower display behavior.
---
Every successful simulated credit pull generates a random integer score from 680 through 820 for each borrower, including repeat pulls. Display borrowers by name with the primary wage earner first.

**Why:** The prototype needs repeatable demonstrations with varying scores rather than a one-time fixed result.

**How to apply:** Keep scores owned by borrower identity when income ranking changes. Repeat pulls must not duplicate liabilities, and frozen-credit behavior still applies.
